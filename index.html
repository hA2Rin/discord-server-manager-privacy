2. 처리하는 개인정보와 목적

  • 생일 등록·표시: Discord 사용자 ID, 생일 월·일, 이용자가 선택 입력한 출생 연도, 나이 공개 설정을 등록 서버별로 저장합니다. 생일 조회, 관리자 목록 표시, 해당 서버에서 생일 축하 메시지를 게시하는 데 사용합니다.
  • 명령어 수행: 명령을 실행할 때 Discord 사용자·서버·채널 ID, 사용자명, 서버명·구성·역할·가입 정보와 필요한 메시지 메타데이터를 Discord API에서 조회해 응답하거나 요청한 관리 작업을 수행합니다. 코드상 이 정보를 별도의 사용자 프로필 데이터베이스에 저장하지 않습니다.
  • 운영 및 오류 확인: 봇 실행 중 오류 정보를 콘솔에 기록할 수 있습니다. 해당 기록의 보관 여부와 기간은 봇을 실행하는 호스팅 환경의 설정에 따릅니다.

봇은 일반 메시지 내용을 수집해 보관하거나, 이용자에게 DM을 보내지 않습니다. 다만 `/clear`는 이용자가 지정한 채널의 메시지를 Discord에서 삭제하고, `/analyze`는 최근 메시지의 시각을 조회해 활동 여부를 계산합니다.

3. 생일 정보의 공개와 서버 범위

생일 등록 시 확인 메시지에 생일 월·일이 표시되어 해당 상호작용이 이루어진 채널 이용자에게 공개될 수 있습니다. 나이 공개를 선택하면 출생 연도에서 계산한 나이도 표시됩니다. 생일 당일에는 등록한 서버의 시스템 채널 또는 봇이 메시지를 보낼 수 있는 채널에 @everyone 알림을 포함한 축하 메시지가 게시될 수 있습니다. 생일 정보는 등록한 서버에서만 조회·게시됩니다.

이용자는 등록 전에 공개 범위를 고려해야 합니다. `/birthday unregister` 명령어로 본인의 생일 정보를 삭제할 수 있습니다. 관리자는 `/birthday list`에서 해당 서버의 등록 정보를 확인하고 삭제할 수 있습니다.

정책 시행 전 저장되었으나 서버를 특정할 수 없는 기존 생일 정보는 다른 서버에서 조회하거나 자동 게시하는 데 사용하지 않습니다. 기존 기록도 `/birthday unregister` 또는 위 문의 이메일로 삭제 요청할 수 있습니다.

4. 보유 및 이용 기간

생일 정보는 이용자가 삭제하거나 해당 서버를 나갈 때까지 보유합니다. 봇이 서버에서 제거되면 해당 서버의 생일 기록을 삭제합니다. 이용자가 탈퇴하면 해당 서버에 등록된 생일 기록을 삭제하며, 서버별 기록은 서로 분리되어 있습니다.

삭제 요청은 확인 후 지체 없이 처리합니다. 백업·호스팅 환경에 잔여 사본이 생기는 경우 해당 환경의 덮어쓰기 주기에 따라 완전히 삭제되기까지 시간이 걸릴 수 있습니다. 법령에 따라 보관해야 하는 정보가 발생하는 경우에는 해당 법령이 정한 기간과 목적에 한해 보관합니다.

5. 제3자 서비스 및 국외 처리

봇은 Discord 계정·서버와 명령 기능을 위해 Discord API를 사용합니다. Discord가 처리하는 정보에는 Discord의 개인정보 처리방침이 적용됩니다. 봇이 실행되는 호스팅 사업자와 서버의 위치는 배포 환경에 따라 달라질 수 있으므로 개인정보의 국외 이전 여부와 구체적인 처리 위치는 해당 배포 환경의 운영자가 확인·고지해야 합니다.

이 정책 페이지는 GitHub Pages에서 제공될 수 있으며, 정책 페이지 접속 기록은 GitHub의 정책에 따라 처리됩니다. 봇에 등록한 생일 정보는 이 정책 페이지나 GitHub 저장소로 전송되지 않습니다.
